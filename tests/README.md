# Tests

Run them all through ctest (on by default; `-DSPPC_BUILD_TESTS=OFF` skips them):

    cmake -S . -B build && cmake --build build && ctest --test-dir build --output-on-failure

Each is linked with the library's object files directly rather than against the shared library, because the library
exports only the public api and these reach into the runtime's own entry points. They are built with `NDEBUG` undefined
in every configuration, since they check with `assert`, and run with `MALLOC_CHECK_=3`. One by hand:

    gcc -std=c17 -g -Iheaders -o /tmp/t tests/test_gt_scheduling.c sources/sppc/sppc.c headers/sppc/asm/gt_switch.S
    MALLOC_CHECK_=3 /tmp/t

A test named `test_*_win.c` is of Windows' own parts and runs only there; every other test is the public api's, for
every platform (Windows runs the ones its port has reached, listed as `SPPC_WINDOWS_PORTED` in CMakeLists.txt).

| File                   | Covers                                                                                                                                                                                                                                                                      |
|------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `test_gt_scheduling.c` | round-robin order, deep recursion on a task stack, a retired handle refusing to resolve, several tasks awaiting one, detach                                                                                                                                                 |
| `test_gt_io.c`         | a task parking on an io_uring read while another runs; a sleeping task not stalling the others, directly and through `sppc_clock_nanosleep` (relative and absolute); a clock the ring can't use falling back, with its error reported                                       |
| `test_gt_safestack.c`  | one unsafe stack per task, restored across switches, with the thread's own preserved                                                                                                                                                                                        |
| `test_gt_locks.c`      | a mutex, rwlock and spin lock contended between two tasks on one thread: the waiter runs the holder rather than blocking, and a release hands the lock to the waiter ahead of the holder taking it straight back; timed mutex/rwlock waits returning `ETIMEDOUT`            |
| `test_gt_stress.c`     | many rounds of spawn/await/detach/yield with heap traffic between them, to shake out corruption                                                                                                                                                                             |
| `test_fs.c`            | read/write and their positioned and vector forms, open flags, dup, truncate, copy_file_range and sendfile, directories, rename, hard and symbolic links, realpath/getcwd/chdir, chown, utimensat, access, temporary names; each with the sppc error for its common failures; on Windows with its permission bits and separators, and its symbolic links where the process may make them |
| `test_net.c`           | address helpers (host-order in, network-order on the wire), TCP and UDP over IPv4 and IPv6 loopback: names, peek, non-blocking (MSG_DONTWAIT and O_NONBLOCK recv / read / accept), shutdown, EPIPE, EADDRINUSE, ECONNREFUSED, socket options read back, poll / select over sockets, a pipe and a closed fd; a server task and a client task on one thread (with a ring) |
| `test_mem.c`           | anonymous and file-backed mappings (private stays private across memprotect, a page into the file, part of one unmapped, EACCES writing through a read-only open), madvise/msync/mlock (ENOMEM over holes), a write to a read-only page faulting; on Windows its views' limits and executable views |
| `test_heap.c`          | every platform: malloc/calloc/realloc/aligned_alloc (alignment, contents kept across each kind of resize, sizes no machine can meet), the `mem*` and `str*` helpers with offsets, overlap and not-found; and the answers sppc gives where C libraries differ (`realloc(p, 0)` frees; alignments below a pointer's size met, non-powers of two refused) |
| `test_time.c`          | every platform: the four POSIX clocks, cpu clocks counting work and not sleep, relative and absolute sleeps on either clock never early, bad flags and times refused; on Windows also Linux's own clocks refused and 2 ms sleeps not rounded to the 15.6 ms tick |
| `test_threads.c`       | create/join/detach/self/equal, once, mutexes (plain and recursive), condition variables (signal, broadcast, timed), rwlocks, spin locks and barriers between os threads, each `try` and timed form, unsafe stacks per thread, a task waiting on a lock a thread holds       |
| `test_files_win.c`     | Windows only: names going at once while open, renames onto open and read-only files, the read-only attribute through chmod/stat/access, programs by extension, uid/gid 0, pipes vs files (ESPIPE, types), O_TRUNC on a read-only open, O_APPEND against another descriptor, readv, fcntl flags and LockFileEx record locks, statvfs, mktemp, getrandom, sendfile into a pipe, a non-ASCII name |
| `test_gt_fibers_win.c` | Windows only: the runtime on fibers — each thread made a fiber and a thread again, every task fiber deleted (no mapping or handle outlives 256 threads, sppc's or foreign), a host's own fiber left alone, floating-point rounding kept per task |
| `test_errno_win.c`     | Windows only: the C library's errno through the shared table (its own numbers past 34, EWOULDBLOCK/ENOTSUP aliases), Win32 and Winsock errors, each from real failing calls where one can produce it |
| `test_init_win.c`      | Windows only: `sppc_init` / `sppc_cleanup` — Winsock up only in between (and a host's own start left alone), critical-error dialogs off, the streams' locks, the UTF-8 locale on the ucrt, a never-awaited task run at cleanup |
| `test_iocp_win.c`      | Windows only: the completion port backend — a receive (and read) parking while a sender task runs, AcceptEx and ConnectEx (an unbound socket bound for it; names, peer, shutdown after; refused), UDP recvfrom/sendto with truncation, sleeps leaving the thread to others and woken in deadline order, a 2 ms sleep not rounded to the 15.6 ms tick, a socket tied to one thread's port used from another, a thread ending with a receive outstanding (cancelled, not written into freed memory). Skipped under the blocking backend |
| `test_fd_win.c`        | Windows only: the fd table — pipes (EOF when writers go, EPIPE when readers go, EBADF the wrong way), close, lowest free fd, dup sharing until the last close, dup2 replacing and growing the table, EMFILE at the limit, stdio swapped through dup2 with the standard handles following, threads churning fds, and a real console's UTF-8 output (split characters, U+FFFD) and line input |
| `test_pthread_win.c`   | Windows only: the pthreads built from Win32 through its POSIX names — threads, keys (destructors on sppc's threads and, via the TLS callback, on foreign ones), once, each mutex kind, conditions, rwlocks, spin locks, barriers, every try/timed form and misuse error |
| `test_process.c`       | environment, pids, getrandom, the standard streams, and every ending: exit (atexit and pending tasks run), halt (nothing runs), abort and each runtime check (message, backtrace naming the caller, status 134), fatal signals; deny_wx refusing writable-and-executable memory. On Windows too, through a re-run child for each ending: its exceptions (an access violation on the thread and in a task, a stack overflow) reported with backtraces and left their own status, and `abort()`'s SIGABRT |
| `test_types`           | sppc's own types and constants: every translation table entry both ways, values the platform must refuse, and the public functions end to end through sppc types (stat, poll, fcntl locks, sockets, socket options, select, readv, barriers, errno)                         |
| `test_strict_c17`      | `sppc.c` and every header it includes compile as `-std=c17 -pedantic-errors -Wall -Wextra -Wvla -Werror` (gcc and clang)                                                                                                                                                    |
